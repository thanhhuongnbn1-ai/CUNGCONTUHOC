# 🎓 ĐỒNG HÀNH CÙNG CON TRƯỞNG THÀNH (VUI HỌC STYLE)
Hệ thống Web App Học tập & Quản lý Giáo dục tích hợp AI dành riêng cho học sinh Tiểu học (Lớp 1 đến Lớp 5).

## Tech Stack
- Frontend: React (Vite) + Tailwind CSS + Lucide React + React Router DOM
- Backend & DB: Supabase (Auth, PostgreSQL, Row Level Security, Storage)
- AI Integration: Google Gemini API (Strict Socratic AI Tutor & AI Content Studio)
- Focus Guardian: JavaScript Browser Focus & Tab Switching Monitor
- Deployment: Vercel SPA
